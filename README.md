# Cargo Data Manager

Cargo Data Manager is a web application developed using Python and Flask.

The project is designed to manage cargo-related data through a simple and user-friendly web interface.

## Features

- Add cargo data
- View cargo data
- Update cargo data
- Delete cargo data
- Simple and clean user interface
- Flask-based backend

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## How to run 
## Install Flask
pip install flask

## Run the application
python app.py
